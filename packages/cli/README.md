# fal-tools

The `fal-tools` command-line interface for immutable planning, bounded fal.ai
generation, objective media auditing, and explicit QA-gated export. Generated
candidates remain in ignored run work directories until selected for export.

Commands are non-interactive and provide versioned JSON result envelopes, JSONL
run events, stable error codes, deterministic exit categories, and
manifest-backed model discovery for autonomous agents.
